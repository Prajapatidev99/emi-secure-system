📲 One-Time Setup (15 minutes)

Do this ONCE on your phone. After this, you can provision unlimited customer devices!

1Install F-Droid App Store

F-Droid is a free app store for open-source apps.

  1. Open browser on your phone
  2. Go to: https://f-droid.org
  3. Tap "Download F-Droid"
  4. Install the APK (allow "Install from unknown sources" if asked)

2Install Termux from F-Droid

Termux is a terminal app that lets your phone run commands.

  1. Open F-Droid app
  2. Search for: Termux
  3. Tap "Install"
  4. Wait for installation to complete
Important: Do NOT install Termux from Google Play Store! It's outdated. Use F-Droid only.

3Install ADB in Termux

ADB (Android Debug Bridge) is the tool that provisions devices.

  1. Open Termux app
  2. Copy and paste these commands one by one:
pkg update && pkg upgrade -y

Wait for it to finish, then run:

pkg install android-tools -y

Verify installation:

adb version
Success! If you see version number, ADB is installed correctly.

4Download Your APK

  1. Download app-release.apk from your server/GitHub
  2. Save it in: Downloads folder
  3. Remember the exact filename

5Create Provisioning Script

This script will make provisioning super easy - just one command!

In Termux, run:

nano provision.sh

Copy and paste this entire script:

#!/data/data/com.termux/files/usr/bin/bash echo "═══════════════════════════════════" echo " EMI Secure Device Provisioner" echo "═══════════════════════════════════" echo "" echo "[1/3] Checking device connection..." adb devices if [ $? -ne 0 ]; then echo "❌ ERROR: No device connected" exit 1 fi echo "" echo "[2/3] Installing EMI Secure APK..." adb install -r /sdcard/Download/app-release.apk if [ $? -ne 0 ]; then echo "❌ ERROR: Failed to install APK" exit 1 fi echo "" echo "[3/3] Setting as Device Owner..." adb shell dpm set-device-owner com.emiseure.customer/.MyDeviceAdminReceiver if [ $? -ne 0 ]; then echo "❌ ERROR: Failed to set device owner" echo "Make sure:" echo " - All Google accounts are removed" echo " - USB debugging is enabled" exit 1 fi echo "" echo "═══════════════════════════════════" echo " ✅ SUCCESS! Device Provisioned" echo "═══════════════════════════════════" echo "" echo "Next steps:" echo "1. Disconnect USB cable" echo "2. Open EMI Secure app" echo "3. Tap 'Sync Status'" echo "4. Copy Android ID and add to dashboard" echo ""

Save the file:

  • Press Ctrl + X
  • Press Y (yes to save)
  • Press Enter

Make it executable:

chmod +x provision.sh
Setup Complete! Your phone is now ready to provision customer devices.

🔄 Provision Customer Device (30 seconds)

Follow these steps for EVERY customer device:

1Prepare Customer Device

  1. Go to Settings → Accounts
  2. Remove ALL Google accounts (very important!)
  3. Go to Settings → About Phone
  4. Tap "Build Number" 7 times
  5. You'll see "Developer mode enabled"
  6. Go back to Settings → Developer Options
  7. Enable "USB Debugging"
  8. Tap "OK" on the warning

2Connect Devices

  1. Plug OTG cable into your phone
  2. Connect customer device to OTG cable
  3. On customer device, you'll see popup: "Allow USB debugging?"
  4. Tap "Allow"

3Run Provisioning Script

  1. On your phone, open Termux
  2. Run the script:
./provision.sh

Wait for the success message!

4Finish Setup

  1. Disconnect USB cable
  2. On customer device, open EMI Secure app
  3. Tap "Sync Status" button
  4. Copy the Android ID shown on screen
  5. Go to dashboard and link the device with this Android ID
Done! Device is now fully provisioned and linked.

💻 Setup with PC/Laptop

1Install ADB on Your Computer

For Windows:

choco install adb

Or download from: https://developer.android.com/tools/releases/platform-tools

For Mac:

brew install android-platform-tools

For Linux:

sudo apt-get install adb

2Prepare Customer Device

  1. Remove all Google accounts
  2. Enable Developer Options (tap Build Number 7 times)
  3. Enable USB Debugging
  4. Connect device to PC via USB cable
  5. Allow USB debugging when prompted

3Provision Device

Open Command Prompt/Terminal and run:

adb devices

You should see your device listed. Then run:

adb install app-release.apk
adb shell dpm set-device-owner com.emiseure.customer/.MyDeviceAdminReceiver
Success! You should see "Device owner set to package com.emiseure.customer"

🔧 Troubleshooting

Error: "Not allowed to set the device owner"

Solution: Make sure ALL Google accounts are removed from the device.

Error: "Device owner is already set"

Solution: Remove existing device owner first:

adb shell dpm remove-active-admin com.emiseure.customer/.MyDeviceAdminReceiver

Error: "adb: command not found"

Solution: ADB is not installed or not in PATH. Reinstall ADB and add to system PATH.

Device not detected

Solution:

  • Check if USB debugging is enabled
  • Try a different USB cable
  • Tap "Allow" on the USB debugging popup
  • Run: adb kill-server then adb start-server
