Device Security Activator

Follow these simple steps for every phone before selling it. This activates the security features to prevent customers from uninstalling the app or resetting the phone.

Requirement: This must be done on a brand new or factory-reset phone before any Google account is added.

1 Prepare the Phone

  1. Turn on the phone. During setup, skip connecting to Wi-Fi and skip adding a Google Account.
  2. Go to Settings > About phone.
  3. Tap on "Build number" seven (7) times fast. A message "You are now a developer!" will appear.
  4. Go back to Settings > System and find Developer options.
  5. Turn on USB debugging.

2 Install the App

  1. Connect the phone to your computer with a USB cable.
  2. Allow the connection on your phone if a popup appears.
  3. Install the EMI Secure APK file onto the phone (your app provider will give you this file).

3 Download PC Tool

You need a small tool from Google to send the security command. Click the link for your computer type:

  • Download for Windows
  • Download for Mac
  • Download for Linux

After downloading, unzip the file to your Desktop or another easy-to-find location.

4 Run the Security Command

  1. Open the unzipped platform-tools folder.
  2. Open a terminal/command window inside this folder:
    • Windows: Hold the `Shift` key and right-click on an empty space inside the folder, then select "Open PowerShell window here" or "Open Command Prompt here".
    • Mac: Right-click on the folder, select "New Terminal at Folder".
  3. Click the button below to copy the security command:
adb shell dpm set-device-owner com.emiseure.customer/.MyDeviceAdminReceiver
  1. Go back to your terminal/PowerShell window, right-click to paste the command, and press Enter.
If it worked, you will see a "Success" message. The phone is now secure!

5 Final Step: Add Google Account

This is the final and most important security lock. It makes the phone unusable if someone tries to reset it using the hardware buttons.
  1. On the phone, go to Settings > Accounts > Add account.
  2. Sign in with a Google account your shop controls.
  3. Open the EMI Secure app and verify you see "Device Admin Active" at the bottom.

Troubleshooting

Error: "device not found"
Make sure the phone is connected, USB debugging is on, and you authorized the connection on the phone's screen.

Error: "...some accounts on the device"
The phone was not factory reset properly. You must factory reset the phone and start over from Step 1.

Error: "Invalid component" or "already an admin"
This happens if you accidentally made the app a regular admin in the phone's settings before running the command. You must factory reset the phone and follow the steps exactly, without opening the app or changing any security settings manually.
